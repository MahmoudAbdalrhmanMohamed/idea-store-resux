# Ideal Stores — Resux

Ideal Stores is a multilingual Resux application built with server rendering, resumable interactions, Vue islands for the few widgets that need the Vue runtime, Tailwind CSS, and a progressive Swiper enhancement.

The application is pinned to **Resux 0.4.0-beta.2** and is configured for Vercel through the Resux Vercel/Nitro deployment target.

## Requirements

- Node.js 22 (see `.nvmrc`)
- npm
- access to the public Ideal Stores API

## Setup

```sh
npm ci
```

Create a local `.env` when you need to override the API origin:

```env
RESUX_PUBLIC_CONSTURL=https://isp.megatron-soft.com/api/v1
```

Then start development:

```sh
npm run dev
```

The development server runs on `http://localhost:6534`.

## Validate

Before opening a pull request or deploying:

```sh
npm run check
npm run build
```

CI runs the same Resux checks and production build on pull requests and on pushes to `main`.

## Production secret

Resux production builds and runtime verification require a private signing secret of at least 32 characters:

```env
RESUX_HALAL_REPORT_SIGNING_SECRET=<private-random-secret>
```

Do not commit this value. Configure it in Vercel for Production and Preview so the build and runtime receive the same secret.

## Vercel

The repository pins the Resux deployment target to Vercel:

```ts
deploy: {
  target: "vercel",
  nitroPreset: "vercel"
}
```

Vercel uses:

- `npm ci` for installation
- `npm run build` for the Resux production build
- Node.js 22 from the repository configuration
- Nitro output generated by Resux

After deployment, the Resux health endpoint is available at:

```txt
/__resux/health
```

The localized application routes use the configured `prefix` i18n strategy, including `/en` and `/ar`.
